# Miir Presenter v0.13

Полировка интерфейса и подготовка к первому реальному тестированию на Android.

## Что изменилось
- Новый тёмный интерфейс «стола мастера» с тёплым акцентом и более контрастными панелями.
- Навигация переименована и упрощена: «Материалы», «Экран игроков», быстрый переход через меню в проекты, подготовку и игру.
- Явный индикатор ручного сохранения.
- Автосохранение рабочего пространства каждые 30 секунд, плюс сохранение при закрытии Activity и переключении приключений.
- Все возможности v0.12 сохранены: кампании/приключения, импорт/экспорт, ветвящиеся сцены, карты, сетка, токены, маркеры, Fog of War, автоматическое раскрытие, карточки КЗ/врем.КЗ/КД, второй экран и Wi‑Fi Player.

## Сборка
Откройте проект в Android Studio с Android SDK 35 и JDK 17. После синхронизации Gradle: Build > Build APK(s).

Это всё ещё тестовая версия. Перед первой игровой сессией рекомендуется проверить Wi‑Fi Player, внешний дисплей и импорт/экспорт на конкретном устройстве.
